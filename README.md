# LocketGoldDks - Đỗ Khắc Sơn

Bản cấu hình do Đỗ Khắc Sơn quản lý.

Upload nội dung gói vào gốc repository Doson163/LocketGoldDks, nhánh main.
Ghi đè hai cấu hình, README.md, SHA256.json và upload js/Locket_Doson163.js.
Tệp js/Locket_DuyVinh09.js cũ có thể xóa sau khi cập nhật; hai cấu hình mới không dùng nó.
Các JavaScript khác giữ nguyên. Đổi tên hiển thị không thay đổi nguồn gốc mã.
Chưa kiểm chứng toàn bộ hành vi trong mã JavaScript bị làm rối hoặc chạy trên thiết bị.
